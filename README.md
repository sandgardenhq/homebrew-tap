# Sandgarden Homebrew Tap

Homebrew formulae for [Sandgarden](https://github.com/sandgardenhq) tools.

## Usage

Tap this repository:

```sh
brew tap sandgardenhq/tap
```

Then install any of the formulae below.

## Formulae

### find-the-gaps

Find documentation gaps between a codebase and its docs site.

- Source: [sandgardenhq/find-the-gaps](https://github.com/sandgardenhq/find-the-gaps)
- Install:

  ```sh
  brew install sandgardenhq/tap/find-the-gaps
  ```

### mdfetch

CLI tool for reading public web pages and converting them to sanitized Markdown.

- Source: [sandgardenhq/mdfetch](https://github.com/sandgardenhq/mdfetch)
- Install:

  ```sh
  brew install sandgardenhq/tap/mdfetch
  ```
